# CoreWorksHQ Ready-to-Use Dashboard

## Run
Open `index.html` in any modern browser. No installation is required.

## Features
- Responsive dark/light dashboard
- CoreWorksHQ branding and About section
- Search, navigation, notifications and theme toggle
- Functional quick-action forms
- Local browser persistence for theme
- Charts, KPI cards, project table and mobile navigation

## Important
This package is a functional front-end prototype. Real authentication, database storage, payroll processing and production APIs require a secure backend before handling actual company or employee data. Do not place passwords in this file.
